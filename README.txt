File Integrity Watcher (hash_watch.py)
========================================
Coded by: Muse Spark (Meta AI assistant)

License: MIT (see LICENSE file)

WHAT IT DOES:
Watches files by SHA-256 and reports BASELINE / CHANGED / APPEARED / DISAPPEARED with an optional alert log.

REQUIREMENTS:
Python 3.8+ only - no extra packages needed (stdlib only).

HOW TO RUN:
python hash_watch.py --help
python hash_watch.py --watch notes.txt --interval 60

PLATFORM:
Windows + Linux + Mac: yes.
